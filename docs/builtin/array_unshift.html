array_unshift()

array_unshift(...$args): int

Parameters

NameTypeDescription
$aarrayarray (by reference)
$...mixedvalues to prepend

Return value

New element count.

Example

$a = [2, 3];
$n = array_unshift($a, 0, 1);
echo $n, " ", implode(",", $a);
