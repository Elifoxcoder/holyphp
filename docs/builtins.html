Regex (5)

PCRE-style pattern matching on the built-in backtracking engine. Patterns use /.../ delimiters with trailing flags i, s, m; \d \w \s classes, captures and alternation are supported. A bad pattern returns false, it does not throw.

preg_match(...$args): mixed
preg_match($pattern, $subject[, &$matches]) — tries the pattern once on $subject. Returns 1 and fills $matches (index 0 = full match, 1..n = capture groups) on success, false on no match or bad pattern. Patterns use /.../ delimiters with flags i (case-insensitive), s (dotall), m (multiline).
preg_match_all(...$args): mixed
preg_match_all($pattern, $subject[, &$matches]) — finds every non-overlapping match. Returns the number of matches and fills $matches with one array per match (each like preg_match's $matches).
preg_replace(...$args): string
preg_replace($pattern, $replacement, $subject) — replaces every match. $replacement may reference captures as $1, $2, … Returns the modified string.
preg_split(...$args): mixed
preg_split($pattern, $subject) — splits $subject at every match of the pattern and returns the pieces as an array.
preg_grep(...$args): mixed
preg_grep($pattern, $array) — returns the elements of $array that match the pattern (keys are re-indexed 0..n).
