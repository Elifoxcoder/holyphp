2 Variables & Types

Variables start with $ like PHP. Types are inferred, but you can add explicit types when you want.

Inferred Types

$x = 42; — compiler infers int

$s = "hello"; — compiler infers string

Explicit Types

$x: int = 42; — pinned to int

$f: float = 3.14; — pinned to float

Available Types

int, float, bool, string, array, mixed, void

types.hphp
Run with: hphp run types.hphp
Practice · lesson 2Create a profile. Set your name, add a city, and print both values. Then add a typed $days: int = 7; variable and print it.
Show one possible solution

Try the steps yourself first. Then compare this small example with your code:

$name = "Ada";
$city = "Zurich";
$days: int = 7;
echo "{$name} lives in {$city}. Practice days: {$days}";

3 Functions

Functions can be typed or untyped. Like PHP, they support default parameters and pass by reference.

functions.hphp
Run with: hphp run functions.hphp
By-reference parameters: Use &$param to modify the caller's variable. The argument must be a variable, not an expression.

7 Memory Safety - Borrow Checker & Ownership

This is what makes HolyPHP special! Compile-time memory safety without garbage collection.

Ownership (own<T>)

Exclusive ownership, moved on assignment

Use-after-move is a compile error

Borrowing (&)

Immutable borrow: many readers

Mutable borrow (&mut): one writer only

Smart Pointers

own<T> - owned, moves

Rc<T> - reference counted

*T - raw pointer (unsafe only)

borrowing.hphp
Run with: hphp run borrowing.hphp
Important: The borrow checker prevents data races at compile time. You cannot have mutable and immutable borrows at the same time, and use-after-move is rejected. These errors are caught by hphp check.

Try these patterns to understand the rules:

// This would be a COMPILE ERROR:
// $a = 5;
// $b = &$a;
// $a += 1;  // cannot assign while borrowed
Practice · lesson 7Update a value safely. Write addFive(int &$value): void, call it with a variable set to 10, and print the value after the call.
Show one possible solution

Try the steps yourself first. Then compare this small example with your code:

function addFive(int &$value): void { $value += 5; }
$score = 10;
addFive($score);
echo $score; // 15

8 Going Further

HolyPHP comes with powerful built-in libraries and tools. Explore them!

Built-in Libraries

ui - Desktop GUI

Native Win32 GUI with themes, widgets, and auto-layout

import "ui";
$app = new App("Hello");
$app->button("Click", "primary", function(){ echo "Hi!"; });
$app->run();

html - HolyHTML Engine

HTML/CSS parser, layout engine, and painter

Render web-like UIs natively without a browser!

ide - HolyIDE

Full IDE for HolyPHP written in HolyPHP itself

hphp run holyide/holyide.hphp

async - Event Loop

Cooperative async with timers, sockets, HTTP

thread - Concurrency

Real OS threads with channels, mutexes, atomics

websocket - RFC 6455

WebSocket server, browser-compatible
