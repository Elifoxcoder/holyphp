Language, runtime, libraries

One toolchain. Several ways to build.

HolyPHP is not PHP running through FPM. Its compiler and runtime power programs written in the language itself.

Types & memory

Safety checks in the compiler

HolyPHP offers inferred types for quick scripts and explicit signatures when you need them. Its borrow checker diagnoses supported conflicting uses before code generation.

How memory safety works →
// Types can be inferred
$count = 3;

// Or stated in a signature
function total(int $a, int $b): int {
    return $a + $b;
}

echo total($count, 4);
