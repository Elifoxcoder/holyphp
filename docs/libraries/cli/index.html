cli

Arguments, questions, tables, progress bars and colors.

Overview Installation Documentation Examples

Overview

Everything a command-line program needs: parse --options and arguments, ask questions, print aligned tables and progress bars, and color the output.

bundled — works offline --name=value, flags, -abc ask / confirm / choose tables, progress, colors

Quick start

import "cli";

$args = cli_args();                       // tool --out=dist -v build
if ($args->has("v")) {
    echo cli_color("verbose mode", "gray");
}
$target = $args->arg(0, "build");
$out = $args->get("out", "build");
echo "building " . $target . " into " . $out;

echo cli_table(["file", "bytes"], [["main.hphp", "812"], ["lib.hphp", "2048"]]);

Installation

In a project

Inside a project (a folder with hphp.yaml, see Projects & packages):

hphp install cli

This adds the library to hphp.yaml, installs it into .hphp/packages/cli/ and pins the exact version in hphp.lock:

require:
  cli: "^1.0"

Use it

import "cli";

cli is bundled with the compiler, so import "cli"; also works in a single file without installing anything, and hphp install works offline.

Outside a project

hphp install cli          # for your user, shared by all scripts
hphp create myapp                 # or start a project, then: hphp install cli

Documentation

Arguments

cli_args() parses the program's own arguments ($argv without the program name); cli_parse($list) parses any list, which is handy in tests.

InputResult
--out=distget("out") → "dist"
--verbosehas("verbose"), get("verbose") → "true"
-xzflags x and z
build srcarg(0) → "build", arg(1) → "src"
-- --not-an-optioneverything after -- is positional
-5negative numbers stay positional
CliArgs methodReturns
has($name)whether the option was given
get($name, $default = "")the value as a string
int($name, $default = 0)the value as an int
arg($i, $default = "")positional argument $i
count()number of positional arguments

Questions

FunctionWhat it does
cli_ask($question, $default = "")a line of input; Enter keeps the default
cli_confirm($question, $default = false)y/n (also j for German keyboards)
cli_choose($question, $options, $default = 0)numbered menu; returns the chosen index

Output

FunctionWhat it does
cli_table($headers, $rows)aligned columns with a rule under the header
cli_progress($done, $total, $width = 30)[#######.......] 25%
cli_color($text, $color)red, green, yellow, blue, magenta, cyan, gray, bold, dim, underline
cli_strip($text)removes color codes
cli_width($text) / cli_pad($text, $n)visible width (ignores colors, counts UTF-8 characters)

Examples

An interactive setup

import "cli";

$name = cli_ask("Project name", "demo");
$kind = cli_choose("Template", ["console", "web", "library"], 0);
if (!cli_confirm("Create " . $name . "?", true)) {
    echo cli_color("cancelled", "yellow");
    exit(1);
}
for ($i = 1; $i <= 20; $i++) {
    echo cli_progress($i, 20);
    usleep(50000);
}
echo cli_color("created " . $name, "green");

A file listing

import "cli";

$rows = [];
foreach (scandir(".") as $f) {
    if ($f != "." && $f != "..") {
        $rows[] = [$f, strval(filesize($f))];
    }
}
echo cli_table(["name", "bytes"], $rows);
