Built into the language

Some features need no library at all: strings, arrays, math, JSON, regular expressions, files, dates, hashing and SQLite are built-in functions. See the documentation.

Publish your own

Start with hphp create mylib -t lib, test it with hphp test, then hphp pkg publish. See Projects & packages.
