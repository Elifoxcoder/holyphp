Packages

Use hphp pkg to search and install packages from the configured registry. The compiler also embeds the libraries shipped in the repository build. The exact set depends on the compiler binary you installed.

hphp pkg help
hphp pkg search
hphp pkg install <name>
Read the package manager guide →

Editor support

The VS Code extension provides HolyPHP syntax highlighting, completions and compiler diagnostics. See the repository’s extension package ↗ for installation and development details.

HolyPHP is actively developed. Some library APIs and platform details may change; use the source and compiler version that match your installed build.
