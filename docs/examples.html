Groups all 235 built-ins thematically, demonstrates the Rust DNA (borrows, unsafe, enums) and prints runtime measurements — including the famous:

$t0 = microtime(true);
$fib = fib(27);

// same machine: PHP 8.5 ~24 ms, Rust ~0.6 ms
// -> HolyPHP ~25x faster than PHP, <2x slower than Rust

word_guess.hphp — playable game

A two-player hangman in 73 lines — readline input, arrays, string building:

function mask_word(string $word, array $found): string {
    $out = "";
    $len = strlen($word);
    for ($i = 0; $i < $len; $i++) {
        $c = substr($word, $i, 1);
        if (in_array($c, $found)) { $out .= $c . " "; }
        else { $out .= "_ "; }
    }
    return $out;
}

$word = strtolower(trim(readline("Geheimes Wort: ")));
$found = [];
// ... loop: guess letters until mask_word shows everything

ui_demo.hphp — UI 2.0 showcase

One theme for the whole window, then widgets that lay themselves out: the button roles, a sign-in card, sliders, a theme picker, a list box, a live progress bar, menus and a timer:

import "ui";

$app = new App("HolyPHP UI 2.0", 880, 780);
$app->theme("midnight")->pad(28)->gap(12)->radius(12);

$app->heading("HolyPHP UI 2.0");
$app->sub("One theme for everything. Zero pixel maths.");

$roles = $app->row();                    // a row lays its children out
$roles->button("Subtle")->style("subtle");
$roles->button("Primary", "primary");
$roles->button("Ghost", "ghost");
$roles->button("Danger", "danger");

$cols = $app->row();                    // two side-by-side columns
$left = $cols->column(400);
$right = $cols->column(400);

$form = $left->card(400);
$form->label("Sign in")->font(13, true);
$email = $form->input("you@example.com");
$form->label("Password");
$pass = $form->input("........");
$form->checkbox("Remember me", true);
$actions = $form->row(370);
$actions->button("Cancel", "ghost")->disable();
$actions->button("Sign in", "primary", function() use ($app, $email) {
    $app->msg("Welcome, {$email->content()}!");
});

$ticks = 0;                              // a timer drives the bar
$bar = $right->card(400)->progress(0);
$status = $right->sub("Idle");
$app->every(400, function() use (&$ticks, $bar, $status) {
    $ticks = $ticks + 1;
    $pct = ($ticks * 5) % 100;
    $bar->progress($pct);
    $status->text("{$pct}% complete");
});

$app->run();

ws_chat.hphp — browser chat server

The library showcase: a chat server that any browser joins — no page reloads, no polling, pure WebSockets:

import "websocket";

$server = new WebSocketServer("tcp://127.0.0.1:9500");
$server->onOpen = function(int $client) use ($server): void {
    $server->broadcast("user " . $client . " joined the chat");
};
$server->onMessage = function(int $client, string $msg) use ($server): void {
    $server->broadcast("user " . $client . ": " . $msg);
};

while ($server->tick()) { usleep(10000); }
hphp build examples/ws_chat.hphp -o wschat.exe
./wschat.exe
# open examples/ws_chat.html in Chrome and start typing

async_demo.hphp — event loop, HTTP, threads

The whole async library in one runnable file: timers with cancellation, a line-oriented TCP server with ACK replies, an in-loop HTTP GET that keeps the loop live, a blocking fetch with the server running on a thread, and raw watchers that see data-then-EOF:

import "async";
import "thread";

$loop = async_line_server("tcp://127.0.0.1:8931", function($c, $line) {
    return "ACK:" . strtoupper($line);        // reply line
});

$loop->httpGet("http://127.0.0.1:8932/hello",
    function($resp) use ($loop) { echo "got " . strlen($resp) . " bytes\n"; $loop->stop(); },
    function($err)  use ($loop) { echo "failed: $err\n"; $loop->stop(); });

$loop->run();
hphp run examples/async_demo.hphp   # prints: ASYNC DEMO: all 5/5 checks passed
