showcase.hphp — every builtin, timed

Groups all 235 built-ins thematically, demonstrates the Rust DNA (borrows, unsafe, enums) and prints runtime measurements — including the famous:

$t0 = microtime(true);
$fib = fib(27);
$t1 = microtime(true);
echo "fib(27) = {$fib} in " . round(($t1 - $t0) * 1000, 2) . " ms\n";
// same machine: PHP 8.5 ~24 ms, Rust ~0.6 ms
// -> HolyPHP ~25x faster than PHP, <2x slower than Rust

Rust-DNA section (verbatim from the example):

// immutable borrow: & = read-only, &mut = writable
function laenge(string $text): int { return strlen($text); }
$w = "borrowed";

    $geheim: int = 42;

word_guess.hphp — playable game

A two-player hangman in 73 lines — readline input, arrays, string building:

function mask_word(string $word, array $found): string {
    $out = "";
    $len = strlen($word);
    for ($i = 0; $i < $len; $i++) {
        $c = substr($word, $i, 1);
        if (in_array($c, $found)) { $out .= $c . " "; }
        else { $out .= "_ "; }
    }
    return $out;
}

$word = strtolower(trim(readline("Geheimes Wort: ")));
$found = [];
// ... loop: guess letters until mask_word shows everything

ui_demo.hphp — desktop GUI tour

Every widget in one window: button with a click counter (by-ref closure capture!), gated input, checkbox, list box, combo, progress + slider, groups, menus, timers:

import "ui.hphp";

$app = new App("HolyPHP UI Demo", 640, 440);
$counterLbl = $app->label("Clicked 0 times", 16, 12);
$clicks = 0;

$greet = $app->button("Greet", 16, 40);
$greet->onClick = function() use ($app, $name, $counterLbl, &$clicks) {
    $clicks = $clicks + 1;                        // real by-ref capture
    $counterLbl->text("Clicked " . $clicks . " times");
};

$slider = $app->slider(430, 70, 180);
$slider->onChange = function(int $v) use ($sliderLbl) {
    $sliderLbl->text("slider: " . $v);            // live while dragging
};

$app->every(2000, function() use ($status) {      // timer
    $status->text("tick " . hrtime(true));
});

$app->run();

ws_chat.hphp — browser chat server

The library showcase: a chat server that any browser joins — no page reloads, no polling, pure WebSockets:

import "websocket.hphp";

$server = new WebSocketServer("tcp://127.0.0.1:9500");
$server->onOpen = function(int $client) use ($server): void {
    $server->broadcast("user " . $client . " joined the chat");
};
$server->onMessage = function(int $client, string $msg) use ($server): void {
    $server->broadcast("user " . $client . ": " . $msg);
};

while ($server->tick()) { usleep(10000); }
hphp build examples/ws_chat.hphp -o wschat.exe
./wschat.exe
# open examples/ws_chat.html in Chrome and start typing
