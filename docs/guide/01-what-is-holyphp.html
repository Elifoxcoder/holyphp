Chapter 1: What is HolyPHP?

Understanding HolyPHP

HolyPHP is a low-level, compiled programming language with the soul of PHP. It combines the familiar, easy-to-learn syntax of PHP with the safety and performance of compiled languages like Rust and C.

Think of it this way: if you know PHP, you'll feel right at home. If you've ever wished PHP was faster, safer, or could compile to a standalone executable, HolyPHP is what you're looking for.

Key Features

🐘 PHP Familiar

Uses $variables, looks like PHP, has 305 compatible built-in functions

⚡ Compiled to Native Code

Compiles directly to machine code, no interpreter or VM. Fast like C!

🔒 Memory Safe

Compile-time borrow checker prevents memory errors, use-after-free, and data races

📦 Standalone Executables

One command produces a single .exe with everything bundled

🎯 Ownership & Borrowing

Rust-inspired memory model without garbage collection

🛠️ Batteries Included

Built-in GUI, HTML/CSS engine, threading, async, WebSocket libraries

How Does It Work?

HolyPHP goes through a complete compilation pipeline:

source .hphp → lexer → parser → type & borrow checker → native binary

The entire toolchain is one self-contained hphp binary. It embeds its own runtime and libraries, so you don't need to install dependencies. When you compile, you get a native executable that runs anywhere (on the same platform) with no runtime required.

When Should You Use HolyPHP?

  • Fast CLI tools - Compile to a single executable, no PHP needed
  • Desktop applications - Use the built-in ui library for native GUIs
  • Performance-critical scripts - Get C-like speed with PHP-like syntax
  • Learning systems programming - Learn ownership/borrowing in a gentler way
  • Safe concurrent programs - Real threads with compile-time safety
Key Concept: HolyPHP gives you the best of both worlds - the productivity of PHP with the performance and safety of compiled languages.
