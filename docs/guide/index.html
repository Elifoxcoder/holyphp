HolyPHP Guide for Beginners

Learn HolyPHP from scratch, one chapter at a time. No prior experience required.

About HolyPHP: A compiled, memory-safe programming language with the soul of PHP and the discipline of Rust. Write like PHP, compile to native machine code with compile-time borrow checking.
